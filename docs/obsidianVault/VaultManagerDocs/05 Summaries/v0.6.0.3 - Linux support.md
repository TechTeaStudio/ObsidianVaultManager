# v0.6.0.3 - Linux support

Linux becomes a shipped target. Each release carries a `linux-x64` file beside `win-x64`, and the tests run on Ubuntu as well as on Windows.

State on 2026-11-03: `VERSION` says 0.6.0.3 and `CHANGELOG.md` has its section. Whether the change is committed or pushed is not recorded here. A push to `product` releases it.

## Shipped

### Added

- A `linux-x64` file next to `win-x64`, each with a SHA-256 checksum. See [[Release]].
- The tests run on Ubuntu as well as on Windows.
- Obsidian installed through Flatpak or Snap is found on Linux, and the log names the install in use. See [[Obsidian]].

### Fixed

- On Linux an open vault looked closed. The process is named `obsidian` there, and the check looked for `Obsidian` case-sensitively, so a change could be written into an open vault.
- On Linux two vaults whose paths differ only in case were treated as one.
- The Linux build crashed at start on a system without ICU, at the first database call. It now runs without ICU.

## Decisions

- [[Linux support]] - the reasons for the Linux build, the libraries it needs, the window frame, the settings lookup and the case rule.

## Intentionally Deferred

Not run yet: a full desktop, Flatpak and Snap Obsidian, Wayland without XWayland, and the full test suite on Linux outside CI. The list and the reasons are in [[Linux support]].
